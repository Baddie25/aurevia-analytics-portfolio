## Overview

This portfolio demonstrates how business data can be transformed into meaningful insights, strategic recommendations, and better management decisions.

The projects use Aurevia Group, a fictional global consumer and retail company, as a shared business environment. This creates a connected analytical portfolio in which commercial performance, market strategy, customer growth, pricing, operations, investment, and predictive decision-making can be explored within a consistent business context.

All company information, transactions, and financial figures are simulated for portfolio and analytical purposes.

## Analytical Approach

The portfolio follows a consistent decision-oriented workflow:

Business Problem → Data Model → Analysis → Business Insight → Strategic Implication → Management Decision

The emphasis is not simply on producing reports or demonstrating technical skills. It is on understanding business performance, identifying opportunities and risks, evaluating alternatives, and translating evidence into actionable recommendations.

## Project 01: Enterprise Performance Command Center

The first project establishes the commercial performance foundation for Aurevia Group.

It includes:

- A relational PostgreSQL data model
- Simulated sales, product, customer, and returns data
- SQL performance analysis
- Revenue, cost, gross profit, and margin measurement
- Discount and returns analysis
- Illustrative target-versus-actual analysis
- Data validation and analytical documentation
- Executive findings and management recommendations

The target-versus-actual analysis uses synthetic planning benchmarks. These are illustrative analytical assumptions, not genuine historical budgets or approved management targets.

**Explore the project:** [`Project 01 — Enterprise Performance Command Center`](projects/01-performance-command-center/README.md)
